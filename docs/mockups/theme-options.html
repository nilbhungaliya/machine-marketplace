Six looks taken from the shop floor

Each palette comes from a real material that the app's users handle every day: primer paint, old lathes, electrical panels, challan books, goods-truck art and Jamnagar brass. Each one also brings its own details, so the themes differ in more than colour. Every theme shows the same Home screen in light and dark mode.

How to reply

Send the theme's name, or mix them, for example "Panel Board colours with the Challan stamp". The colour roles are the same in every theme, so swapping one part between themes is easy.

Next, the chosen theme becomes the token set for 4–5 sample screens: Home, Search results, Listing page, Sell wizard, and Chat with an offer.
